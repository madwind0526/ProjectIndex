# Rules

> 이 프로젝트의 규칙과 컨벤션. 모든 sub-agent가 반드시 따라야 함.

## G-01: 코드 주석은 영어만 사용 (MANDATORY)

**규칙:** 모든 코드 주석(`//`, `/* */`, `///`)은 영어로 작성. 한글 주석 금지.
**이유:** 소스 파일 내 한글은 인코딩 문제 및 빌드 오류를 유발할 수 있음.
**적용 시점:** 코드 작성 또는 수정 시 항상. UI 텍스트(사용자에게 보이는 문자열)는 한국어 유지.

## P-01: 삭제는 카드 숨김만

**규칙:** 카드의 삭제 버튼은 `hidden` 표시만 하고 폴더·GitHub 저장소는 절대 지우지 않는다.
**이유:** 이 앱은 다른 프로젝트들의 색인일 뿐이다. 실수로 눌러도 데이터가 사라지면 안 된다.
**적용 시점:** 삭제·정리 기능을 추가할 때. 사라진 폴더의 수정 기록도 지우지 않는다(드라이브가 잠깐 꺼진 경우 보호).

## P-02: 직접 수정한 카드는 AI가 덮어쓰지 않음

**규칙:** `edited: true`인 카드는 새로고침/Update All에서 요약·상세·카테고리를 LLM이 바꾸지 않는다. 명시적인 "AI 상세 요약"(`force=1`)만 덮어쓴다.
**이유:** LLM 분류가 틀릴 수 있어(예: Voyager) 사람이 고친 값이 우선해야 한다.

## P-03: 토큰은 화면과 디스크에 남기지 않음

**규칙:** git remote URL은 `cleanRemote()`로 자격 증명을 제거한 뒤에만 사용한다.
**이유:** 일부 프로젝트의 remote에 GitHub 토큰이 들어 있다.

## P-04: 사용자 데이터 파일은 읽기 전에 덮어쓰지 않음

**규칙:** `data/runtime/settings.json`을 스크립트로 수정할 때는 먼저 파싱에 성공했는지 확인한다.
**이유:** 파싱 실패 후 `null`을 쓰면 사용자가 저장한 설정이 사라진다(trouble-shooting 참고).
